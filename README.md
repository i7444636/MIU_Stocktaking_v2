# 재고대조분석기_v2

매장 실사 스캔 자료와 공동판매 재고 마스터를 대조하고, 이미 판매된 상품을 제외한 미스캔(누락 의심) 항목을 찾아 Excel 보고서로 내려받는 브라우저 도구입니다.

## 사이트

https://i7444636.github.io/MIU_Stocktaking_v2/

## 필요한 파일

1. **스캔 취합본**
   - `통합` 시트
   - A열: 지점명
   - B열: 바코드
2. **공동판매 마스터**
   - `입고` 시트
   - B열: 장부상 위치
   - D열: 상품명
   - E열: 금액
   - G열: 바코드
   - K열: 판매 값
   - 업로드 전에 K열 수식을 값으로 붙여넣고 저장해야 합니다.
3. **전매장 매입매출장**
   - `매출` 시트
   - E열: 바코드
   - H열: 판매 수량
   - 동일 바코드가 여러 행에 있으면 H열 수량을 합산하며, 합계가 1 이상일 때만 판매된 것으로 처리합니다.

## 판정 기준

- **정상(매칭)**: 실사 바코드가 마스터에 있고 실사 지점과 장부상 위치가 같습니다.
- **위치불일치**: 바코드는 마스터에 있지만 실사 지점과 장부상 위치가 다릅니다.
- **장부부재(신규)**: 실사에는 있지만 마스터에는 없는 바코드입니다.
- **미스캔(누락의심)**: 마스터에는 있지만 실사되지 않았고, 공동판매 마스터 K열 판매 값이 1 미만이며, 전매장 매출에서 해당 바코드의 H열 수량 합계도 1 미만인 바코드입니다.

## 사용 방법

1. 사이트에서 세 파일을 차례로 업로드합니다.
2. `재고 대조 분석 시작`을 누릅니다.
3. 결과 건수를 확인한 뒤 `Excel 보고서 다운로드`를 누릅니다.

## 데이터 처리

Excel 파일은 사용자의 브라우저 안에서만 처리됩니다. 업로드한 파일 내용은 별도 서버로 전송하거나 저장하지 않습니다.

## 기술 구성

- 단일 HTML/CSS/JavaScript 페이지
- SheetJS(xlsx)로 브라우저에서 Excel 파일 읽기 및 결과 파일 생성
- GitHub Pages 배포
